# Image Hunter 0.8.5

**Файлы переезжают мышью в папки дерева.** Во вкладке «Мои картинки» выделенные файлы (Ctrl/Shift) теперь можно зажать и бросить на любую папку в дереве слева — вложенную, диск, «Домой» или избранное: файлы перенесутся туда, с Ctrl — скопируются, как в Проводнике. Папка под курсором подсвечивается, свёрнутая сама раскрывается через мгновение. Перенос идёт в фоне — окно не замирает даже на сетевом диске; лента обновляется сама: уехавшие плитки исчезают, бросок в открытую папку показывает приехавшие файлы. Имена не затираются — при совпадении файл сохраняется как «имя-1.ext», всё видно в статусе и «Журнале».

# Image Hunter 0.8.4

**Подпись плитки: имя + разрешение.** Во вкладке «Мои картинки» под именем файла на каждой плитке теперь видно исходное разрешение картинки — «1920×1080», серым на шаг мельче имени, тем же форматом, что и в статусе полноэкранного просмотра. Разрешение считывается из заголовка файла в фоновом потоке, вместе с миниатюрой (с учётом EXIF-поворота), и хранится прямо внутри кэша миниатюр — повторное открытие папки, включая сетевую, по-прежнему мгновенное и не читает файлы заново. Текст плитки остаётся чистым именем файла: переименование, поиск по имени и перетаскивание работают как раньше.

# Image Hunter 0.8.3

**Поиск с телефона работает даже там, где поисковики не пускают.** В режиме «Интернет» — пять поисковиков: **Openverse** и **Wikimedia** (официальные API — работают всюду, без ключей), **DuckDuckGo** и **Bing** (с честными ошибками вместо тишины) и **«Программа»** — телефон показывает ту же выдачу, что открыта во вкладке «Поиск картинок» программы: программа ищет настоящим браузером и сама передаёт телефону «очищенные и облегчённые» плитки. Вечного «Ищу…» больше нет — у запросов таймаут 60 с, у Bing пустая оболочка — честная ошибка с подсказкой. И главное: вся деятельность веб-сервера и API теперь видна в «Журнале» программы — подключения, поиски с телефона, переименования, удаления, удаление фона, скачивания и отказы «только просмотр».

# Image Hunter 0.8.2

**Модули — в отдельном меню.** В строке меню появился пункт **«Модули»** (слева от «Справки»): установка, удаление и настройки всех подключаемых модулей теперь в одном месте.

- **Удаление фона (rembg):** установка или удаление модуля одним пунктом (с подтверждением и показом, сколько места занимают модели), подменю «Модель rembg» с галочкой на выбранной — u2netp (быстрая), u2net (качественнее), isnet-general-use (самые чистые края). Заголовок раздела показывает, установлен ли модуль.
- **Веб-сервер (доступ с телефона):** запуск и остановка прямо из меню, галочка «Автостарт с программой», пункт «🌐 Панель веб-сервера…» — окно с портом, токеном, QR-кодом и режимом «только просмотр». Заголовок раздела показывает состояние: «Сервер работает — порт N» или «остановлен».
- Эти же пункты убраны из старых мест: контекстного меню ленты «Моих картинок» (там осталась только операция «🪄 Удалить фон») и кнопки «🌐» в статус-баре, которой больше нет. Пункты меню всегда показывают актуальное состояние — меню пересобирается при каждом открывании.

# Image Hunter 0.8.1

**🔎 Поиск картинок из интернета — теперь и с телефона.** В веб-интерфейсе модуля «🌐» появилась кнопка **🔎** («Интернет»): вводите запрос — плитки выдачи DuckDuckGo или Bing (выбор в шапке) показываются той же лентой, что и файлы. Клик — полный просмотр оригинала через сервер (сайты с проверкой Referer напрямую телефону картинку не отдают), «⬇️» — сохранить оригинал на само устройство, «💾» — в папку на компьютере, открытую в режиме «Файлы». Плитки отмечаются плюсиком — как чекбоксы выдачи в программе; плавающая кнопка «⬇ N» скачивает отмеченные одним фоновым заданием, прогресс и итог видны в статусе и журнале. Скачивание идёт по правилам настольной программы: лестница попыток с Referer, раскрытие Cloudflare-обёрток, имена без затираний (`cat-1.png`), лимит 100 МБ. Поиск доступен и в режиме «только просмотр» — он ничего не меняет на компьютере; сохранение в папку — недоступно.

# Image Hunter 0.8.0

**🌐 Веб-сервер — управление программой с телефона.** Кнопка «🌐» в статус-баре поднимает маленький веб-сервер (подключаемый и полностью удаляемый модуль): телефон в той же сети сканирует QR-код и получает мобильный интерфейс с почти всей программой — лента папок с миниатюрами, поиск по имени, полный просмотр со свайпами, переименование, удаление, удаление фона rembg с прогрессом, журнал. Доступ по токену (QR/ссылка), режим «только просмотр», автостарт по желанию; без запуска модуль ничего не занимает. Отдельный процесс: `python -m app.server --port 8477 --token …`. Внутреннее API — `app/server/api.py`: те же правила переименования, тот же кэш миниатюр, тот же формат «*_nobg.png».

## 🆕 Новое за последние версии

### ✏️ Переименование файлов — v0.7.17
Имена правятся прямо в ленте «Моих картинок», не выходя из программы:
- пункт **«✏️ Переименовать»** в правом клике по плитке;
- клавиша **F2**;
- **двойной клик по имени файла** под миниатюрой (двойной клик по самой картинке по-прежнему открывает её в системном просмотрщике).

Редактор открывается с выделенным именем **без расширения** — как в Проводнике: Enter или клик мимо применяют правку, Esc отменяет. Само переименование идёт в рабочем потоке — на сетевом диске окно не замирает. Имя проверяется заранее: пустое, с точкой/пробелом на конце или запрещёнными Windows-символами (`\ / : * ? " < > |`) принято не будет, конфликт с существующим файлом вернёт старое имя с объяснением. Каждый итог — в «Журнале».

### ▦ Шахматка под прозрачными картинками — v0.7.16
Под PNG, GIF, WebP и результатами «*_nobg.png» область просмотра рисует классическую сетку из **белых и серых квадратов** — сразу видно, где настоящая прозрачность, а где нарисованный белый фон. Размер клеток регулируется **ползунком** (4–32 px), выбор запоминается. Включается только для картинок с альфа-каналом, квадраты едут вместе с картинкой при прокрутке и остаются резкими на HiDPI-экранах.

### 💾↩ Выбор после удаления фона + живой статус модуля — v0.7.15
- После обработки пачки открывается окно **«Сохранить результат или вернуть оригиналы?»** с превью на шахматке; окно немодальное — каждый результат можно открыть в полном размере. «↩ Вернуть оригиналы» удаляет только результаты этой пачки — оригиналы не менялись никогда.
- Скачивание модели u2netp видно в **статусной строке**: «Скачивается модель u2netp: 1,2 МБ из 4,7 МБ (26 %)». Модель качает само приложение, pooch проверяет хеш.

### 🪄 Удаление фона прямо из программы — v0.7.12–v0.7.14
Кнопка «🪄 Удалить фон» и пункт в правом клике: фон убирается нейросетью **rembg** (модель u2netp), результат сохраняется рядом как «*имя*_nobg.png». Модуль ставится и убирается из программы без консоли, модель докачивается автоматически.

### 📜 Текущее задание в статусной строке — v0.7.13
Каждая строка журнала дублируется в статус-бар: что бы ни делала программа — ищет, скачивает, удаляет фон — видно без переключения вкладок.

## 🧭 Кратко о программе

- **📂 Мои картинки** — дерево дисков и папок (быстрый поиск папок, избранные папки), лента миниатюр с ленивой загрузкой и дисковым кэшем, поиск по имени, удаление в корзину, переименование, удаление фона.
- **🔎 Поиск картинок** — вкладки-браузер с 13 поисковиками (Яндекс, Google, DuckDuckGo, Brave, Yahoo, Ecosia, Startpage, Mojeek, Bing, Baidu, Sogou, Naver, Mail.ru); «Найти везде» открывает запрос сразу во всех; чекбоксы на плитках выдачи — скачайте отмеченные оригиналы в один клик.
- **⬇️ Скачивание** — массовое сохранение по ссылкам: до 6 файлов параллельно, стриминговая запись, конвертация в WebP.
- **📜 Журнал** — хроника всей работы: события, ошибки с причинами, тайминги.

Особый упор — **быстрая работа с сетевыми дисками** (SMB/NAS, Windows-шары): папка читается одним проходом, миниатюры строятся только для видимой части списка и кэшируются на диске, все сетевые операции — вне GUI-потока.

## 📦 Установка

**Windows** (PowerShell):
```powershell
irm https://codeload.github.com/teliy/image-hunter/zip/refs/heads/main -OutFile "$env:TEMP\ih.zip"; Expand-Archive "$env:TEMP\ih.zip" "$env:TEMP\ih-src" -Force; powershell -NoProfile -ExecutionPolicy Bypass -File "$env:TEMP\ih-src\image-hunter-main\install.ps1"
```

**Linux / macOS**:
```bash
curl -fsSL https://raw.githubusercontent.com/teliy/image-hunter/main/install.sh | bash
```

Установщик сам поставит Python и зависимости, создаст ярлык и встроенный апдейтер. Требования: Windows 10+ / Linux, Python 3.10+ (установщик предложит поставить).

Обновление уже установленной копии — прямо из программы (меню ⟳ в статус-баре) или теми же командами.
