Ещё: в README раздел «Установка» поднят к началу, сразу после вступления.

# Image Hunter 0.8.15

**Установленные модули обновляются из программы.** Если Florence-2, LaMa или rembg обновились у разработчиков, Image Hunter больше не остаётся со старыми версиями: в меню «Модули» у каждого установленного модуля появился пункт «Обновить». # Image Hunter 0.8.14

**Удаление водяных знаков переписано: tiled-знаки («НАТАР» по всему кадру) больше не превращают фото в серую кашу.** В версии 0.8.13 такой знак находился задачей «watermark»-grounding, которая отвечала 3–4 гигантскими боксами на весь кадр, — маска накрывала 100% картинки, и LaMa «достроил» всё подряд (репорт: «Знаки не удалил. Получилась какая-то ерунда»). Теперь знак ищет OCR Florence-2 (`<OCR_WITH_REGION>`): точные повёрнутые рамки каждой надписи, в два прохода (оригинал + авто-контраст — бледные экземпляры больше не ускользают), с фильтром насыщенности, который отличает серый знак от цветного текста этикетки товара и не трогает её. Знак-логотип без текста по-прежнему ловит grounding, но боксы-гиганты (>25% кадра) отбрасываются, а если маска всё же накрыла больше 60% кадра — файл честно помечается ошибкой, картинка не портится. Живой прогон на картинке репорта: знак убран в том числе с красной коробки, этикетка «MAIN / 6D14 6D16» цела, LaMa справился за 9 секунд вместо 182. Достаточно обновить программу и снова нажать «🧽 Убрать водяные знаки» — на файлах, испорченных раньше, лучше удалить старый «*_nowm» и обработать оригинал заново.

# Image Hunter 0.8.13

**Установка модуля «Водяные знаки» чинится на Python 3.13+, и конвейер впервые доведён до живого запуска.** Ошибка «…numpy … note: This is an issue with the package mentioned above, not pip» возникала из-за того, что IOPaint 1.6.0 пинует gradio 4.21.0 (веб-морду, конвейеру она не нужна), а тот требует numpy 1.x — на Python 3.13+ у него нет готовых сборок, и pip пытался собрать numpy из исходников. Теперь gradio из установки исключена (как раньше Pillow), а вместе с зависимостями ставятся шимы `standard-imghdr` и `setuptools` — iopaint и pinned diffusers импортируют модули, удалённые из стандартной библиотеки новых Python. Заодно убрана мина после установки: big-lama качается до ModelManager (иначе iopaint отвечал «Unsupported model: lama»). Весь конвейер проверен живьём на Python 3.13: LaMa закрашивает, Florence-2 находит знаки. Пользователю достаточно снова нажать «🧽 Убрать водяные знаки» — установка пройдёт сама.

# Image Hunter 0.8.12

**Установка модуля «Водяные знаки» чинится на новых Python (3.12/3.13).** Ошибка «Не удалось установить модуль удаления водяных знаков … KeyError: '__version__'» возникала из-за того, что IOPaint требует ровно Pillow==9.5.0, а у этой версии нет готовых сборок под новые Python — pip пытался собрать старый исходник и падал. Заодно «Удалить модуль» стало вычищать и прямые зависимости iopaint (gradio, diffusers и прочие), которые раньше оставались в системе. Пользователю достаточно снова нажать «🧽 Убрать водяные знаки» — установка пройдёт сама.

- **двойной клик по имени файла** под миниатюрой (двойной клик по самой картинке по-прежнему открывает её в системном просмотрщике).

Редактор открывается с выделенным именем **без расширения** — как в Проводнике: Enter или клик мимо применяют правку, Esc отменяет. Само переименование идёт в рабочем потоке — на сетевом диске окно не замирает. Имя проверяется заранее: пустое, с точкой/пробелом на конце или запрещёнными Windows-символами (`\ / : * ? " < > |`) принято не будет, конфликт с существующим файлом вернёт старое имя с объяснением. Каждый итог — в «Журнале».

### ▦ Шахматка под прозрачными картинками — v0.7.16
Под PNG, GIF, WebP и результатами «*_nobg.png» область просмотра рисует классическую сетку из **белых и серых квадратов** — сразу видно, где настоящая прозрачность, а где нарисованный белый фон. Размер клеток регулируется **ползунком** (4–32 px), выбор запоминается. Включается только для картинок с альфа-каналом, квадраты едут вместе с картинкой при прокрутке и остаются резкими на HiDPI-экранах.

### 💾↩ Выбор после удаления фона + живой статус модуля — v0.7.15
- После обработки пачки открывается окно **«Сохранить результат или вернуть оригиналы?»** с превью на шахматке; окно немодальное — каждый результат можно открыть в полном размере. «↩ Вернуть оригиналы» удаляет только результаты этой пачки — оригиналы не менялись никогда.

## 🧭 Кратко о программе

- **📂 Мои картинки** — дерево дисков и папок (быстрый поиск папок, избранные папки), лента миниатюр с ленивой загрузкой и дисковым кэшем, поиск по имени, удаление в корзину, переименование, удаление фона.
- **🔎 Поиск картинок** — вкладки-браузер с 13 поисковиками (Яндекс, Google, DuckDuckGo, Brave, Yahoo, Ecosia, Startpage, Mojeek, Bing, Baidu, Sogou, Naver, Mail.ru); «Найти везде» открывает запрос сразу во всех; чекбоксы на плитках выдачи — скачайте отмеченные оригиналы в один клик.
- **⬇️ Скачивание** — массовое сохранение по ссылкам: до 6 файлов параллельно, стриминговая запись, конвертация в WebP.
- **📜 Журнал** — хроника всей работы: события, ошибки с причинами, тайминги.

Особый упор — **быстрая работа с сетевыми дисками** (SMB/NAS, Windows-шары): папка читается одним проходом, миниатюры строятся только для видимой части списка и кэшируются на диске, все сетевые операции — вне GUI-потока.

## 📦 Установка

**Windows** (PowerShell):
```powershell
irm https://codeload.github.com/teliy/image-hunter/zip/refs/heads/main -OutFile "$env:TEMP\ih.zip"; Expand-Archive "$env:TEMP\ih.zip" "$env:TEMP\ih-src" -Force; powershell -NoProfile -ExecutionPolicy Bypass -File "$env:TEMP\ih-src\image-hunter-main\install.ps1"
```

**Linux / macOS**:
```bash
curl -fsSL https://raw.githubusercontent.com/teliy/image-hunter/main/install.sh | bash
```

Установщик сам поставит Python и зависимости, создаст ярлык и встроенный апдейтер. Требования: Windows 10+ / Linux, Python 3.10+ (установщик предложит поставить).

Обновление уже установленной копии — прямо из программы (меню ⟳ в статус-баре) или теми же командами.
