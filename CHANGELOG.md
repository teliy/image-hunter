# Журнал изменений Image Hunter

Все заметные изменения программы, новые версии сверху. Установка — в [README](README.md).

## 0.8.0 — 2026-11-04

**Веб-сервер: управление программой с телефона.** Новый подключаемый и полностью удаляемый модуль (`app/server/`): кнопка **🌐** в статус-баре поднимает маленький HTTP-сервер, телефон в той же сети открывает адрес (QR-код в окне модуля) и получает мобильный веб-интерфейс с почти всей функциональностью программы.

- **С телефона доступно:** лента папок с миниатюрами (общий с программой дисковый кэш миниатюр), поиск по имени (вглубь подпапок, «игнорировать дефис», предел результатов), полный просмотр со свайпами и клавишами, переименование, удаление в корзину и окончательно, удаление фона rembg фоновым заданием с опросом прогресса, диски и избранные папки, хвост журнала.
- **Внутреннее API** (`app/server/api.py`) — чистые операции над файловой системой без Qt-виджетов: те же правила переименования, что по F2 в программе; тот же формат «X_nobg.png» у rembg; однопроходный scandir-поиск.
- **Безопасность:** обязательный токен (ссылка с токеном → cookie запоминается), режим «только просмотр», ограничение корней; сравнение токена постоянным временем; страница интерфейса и API не отдают ничего без токена.
- **Модульность:** интерфейс страницы — один HTML без внешних файлов (работает в LAN без интернета), RU/EN с автовыбором; сервер можно поднять и отдельным процессом — `python -m app.server --port 8477 --token …` (--view-only, --restrict, --lifetime); до первого запуска модуль не импортируется и ничего не занимает; удаление папки `app/server/` + кнопки «🌐» полностью убирает модуль.
- **QR-код** в окне модуля рисует библиотека qrcode — ставится кнопкой прямо из окна (как rembg), без неё адрес показывается текстом.
- Механика: `app/server/` — api.py / httpd.py (stdlib ThreadingHTTPServer, HTTP/1.1, докачка Range) / webui.py / manager.py / dialog.py + `__main__.py`; кнопка «🌐» и автостарт в main_window.py (лениво, закрытие окна гасит сервер); i18n ru/en/zh — 23 новых ключа. Тесты: `scripts/test_server.py` — реальные HTTP-запросы на случайном порту (55 проверок): токен, страница, лента, кэш (включая переиспользование кэша программы при size≤160), Range/206/416, скачивание, правила переименования (запрет символов, конфликт, «только регистр»), удаление (корзина/окончательное/ошибки), «только просмотр», ограничение корней, поиск (вглубь/дефис/предел), drives, журнал через кольцевой буфер, rembg-маршруты, занятый порт, менеджер настроек, CLI-процесс; смоук — версия 0.8.0, test_checker/test_rename/test_perf_logging/test_status_log/test_i18n/test_delete_restore/test_tree/test_folder_search/test_rembg — 0.8.0, README×3.


## 0.7.17 — 2026-11-03

**Переименование файлов — F2, двойной клик по имени и пункт меню.** Имена картинок правятся прямо в ленте «Моих картинок»: пункт «✏️ Переименовать» в правом клике по плитке, клавиша **F2** или двойной клик по **имени файла** под миниатюрой. Редактор открывается с выделенным именем без расширения (как в Проводнике) — Enter или клик мимо применяют правку, Esc отменяет. Двойной клик по самой картинке по-прежнему открывает её в системном просмотрщике. Само переименование идёт в рабочем потоке — на сетевом диске окно не замирает. Новое имя проверяется заранее: пустое, с точкой/пробелом на конце или с запрещёнными Windows-символами (`\ / : * ? " < > |`) принято не будет, конфликт с существующим файлом вернёт старое имя с объяснением в статусе. Каждый итог — в «Журнале».

## 0.7.16 — 2026-11-02

**Фон прозрачных картинок — «шахматка» с ползунком.** Под прозрачными картинками (PNG, GIF, WebP, результаты «*_nobg.png») область просмотра рисует классическую сетку из белых и серых квадратов — сразу видно, где настоящая прозрачность, а где нарисованный белый фон. Размер клеток регулируется ползунком на панели, выбор запоминается. Шахматка включается только для картинок с альфа-каналом, квадраты едут вместе с картинкой при прокрутке и остаются резкими на HiDPI.

## 0.7.15 — 2026-11-02

**Выбор после удаления фона + статус модуля в статусной строке.** После обработки пачки открывается окно «Сохранить результат или вернуть оригиналы?» с превью результата на шахматке; окно немодальное — каждый результат можно открыть в полном размере. «↩ Вернуть оригиналы» удаляет только результаты этой пачки — оригиналы не менялись никогда. Скачивание модели rembg теперь показывает прогресс в статусной строке: «Скачивается модель u2netp: 1,2 МБ из 4,7 МБ (26 %)» — модель качает само приложение, pooch проверяет хеш.

## 0.7.14 — 2026-11-02

**Удаление фона без консоли (pythonw), запуск без замираний на сетевом диске.** Исправлено падение скачивания модели при запуске без консоли (`'NoneType' object has no attribute 'write'`); перечисление дисков вынесено в рабочий поток — первый заход на ещё не подключённый сетевой диск больше не замирает интерфейс на ~2 с.

## 0.7.13 — 2026-11-02

**Текущее задание видно внизу, в статусной строке.** Каждая строка журнала (события, предупреждения, ошибки) дублируется в статус-бар: что бы ни делала программа — ищет, скачивает, удаляет фон — видно без переключения вкладок. Сообщение держится, пока его не сменит следующее.

## 0.7.12 — 2026-11-02
