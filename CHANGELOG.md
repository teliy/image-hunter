# Журнал изменений Image Hunter

Все заметные изменения программы, новые версии сверху. Установка — в [README](README.md).

## 0.7.17 — 2026-11-03

**Переименование файлов — F2, двойной клик по имени и пункт меню.** Имена картинок правятся прямо в ленте «Моих картинок»: пункт «✏️ Переименовать» в правом клике по плитке, клавиша **F2** или двойной клик по **имени файла** под миниатюрой. Редактор открывается с выделенным именем без расширения (как в Проводнике) — Enter или клик мимо применяют правку, Esc отменяет. Двойной клик по самой картинке по-прежнему открывает её в системном просмотрщике. Само переименование идёт в рабочем потоке — на сетевом диске окно не замирает. Новое имя проверяется заранее: пустое, с точкой/пробелом на конце или с запрещёнными Windows-символами (`\ / : * ? " < > |`) принято не будет, конфликт с существующим файлом вернёт старое имя с объяснением в статусе. Каждый итог — в «Журнале».

## 0.7.16 — 2026-11-02

**Фон прозрачных картинок — «шахматка» с ползунком.** Под прозрачными картинками (PNG, GIF, WebP, результаты «*_nobg.png») область просмотра рисует классическую сетку из белых и серых квадратов — сразу видно, где настоящая прозрачность, а где нарисованный белый фон. Размер клеток регулируется ползунком на панели, выбор запоминается. Шахматка включается только для картинок с альфа-каналом, квадраты едут вместе с картинкой при прокрутке и остаются резкими на HiDPI.

## 0.7.15 — 2026-11-02

**Выбор после удаления фона + статус модуля в статусной строке.** После обработки пачки открывается окно «Сохранить результат или вернуть оригиналы?» с превью результата на шахматке; окно немодальное — каждый результат можно открыть в полном размере. «↩ Вернуть оригиналы» удаляет только результаты этой пачки — оригиналы не менялись никогда. Скачивание модели rembg теперь показывает прогресс в статусной строке: «Скачивается модель u2netp: 1,2 МБ из 4,7 МБ (26 %)» — модель качает само приложение, pooch проверяет хеш.

## 0.7.14 — 2026-11-02

**Удаление фона без консоли (pythonw), запуск без замираний на сетевом диске.** Исправлено падение скачивания модели при запуске без консоли (`'NoneType' object has no attribute 'write'`); перечисление дисков вынесено в рабочий поток — первый заход на ещё не подключённый сетевой диск больше не замирает интерфейс на ~2 с.

## 0.7.13 — 2026-11-02

**Текущее задание видно внизу, в статусной строке.** Каждая строка журнала (события, предупреждения, ошибки) дублируется в статус-бар: что бы ни делала программа — ищет, скачивает, удаляет фон — видно без переключения вкладок. Сообщение держится, пока его не сменит следующее.

## 0.7.12 — 2026-11-02

**Удаление фона прямо из программы — rembg как модуль.** Кнопка «🪄 Удалить фон» и пункт в правом клике: фон убирается нейросетью (u2netp), результат сохраняется рядом как «*имя*_nobg.png». Модуль ставится и убирается из программы без консоли, модель докачивается автоматически.

## 0.7.11 — 2026-11-02

**Итоги полного аудита кода — 9 правок стабильности и скорости.** GIF и AVIF не читаются в GUI-потоке, скачивание пишется атомарно, HTTP-сессия переиспользуется, подсветка дерева асинхронная и др.
